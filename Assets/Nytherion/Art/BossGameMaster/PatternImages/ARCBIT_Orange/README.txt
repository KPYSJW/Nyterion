ARCBIT 레이저 주황/금색 변형

시작 21장 / 몸통 13장 / 끝 13장. 첨부된 원본 폴더의 번호 순서 그대로.
복사한 PNG는 원본과 바이트가 동일합니다. Unity TextureImporter의 채널 매핑만 R=B, G=G, B=R, A=A로 설정했습니다.
따라서 Unity에서 주황/금색으로 표시되고, 파일 탐색기의 원본 PNG 미리보기에서는 파란색으로 보입니다.
흰색(R=G=B)과 투명도는 그대로 유지됩니다. 32x32, PPU32, Point, 무압축.
각 Preview 프리팹은 해당 부위의 24fps 반복 애니메이션을 확인하기 위한 것입니다.
이번 작업은 색상 변경 및 부위별 미리보기까지입니다. LineRenderer 통합과 패턴 실행은 연결하지 않았습니다.
C# 및 기존 셰이더는 수정하지 않았습니다.
Unity swizzle 문서: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/TextureImporterSwizzle.html
