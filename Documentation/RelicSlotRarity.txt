유물 슬롯의 등급별 프레임 (2026-10-16)

- 유물 보관 슬롯과 장착 슬롯에 인벤토리와 동일한 5등급 배경 스프라이트를 연결했다.
- 일반: 회색, 고급: 초록색, 희귀: 파란색, 영웅: 보라색, 전설: 노란색.
- 빈 슬롯은 기존 보관·장착용 기본 배경을 사용한다.
- UI 전체 갱신·장착·해제·페이지 변경 시 배경을 초기화하고 현재 유물의 등급을 다시 적용한다.
- 배치 강조는 임시 색상만 변경하며, 강조 해제 시 원래 색과 등급별 프레임을 유지한다.
- 아이콘의 색상·크기는 변경하지 않았다. PixelPerfectSlotFrame의 보정은 스프라이트 전환 후에도 적용한다.

변경 대상
- RelicSlotVisual.cs, RelicSlotCell.cs, RelicGridUI.cs.
- Assets/Prefabs/UI/Relic/StorageSlot.prefab, RelicSlotCell.prefab.
- 프리팹은 Unity PrefabUtility로 수정하고 GUID를 유지했다.
- 원본 프리팹 및 meta: Documentation/RelicSlotRarityOriginals.zip.

검증
- Tools/Nytherion/Relics/Apply And Verify Rarity Slot Frames.
- 결과: output/relic-slot-rarity/verification.txt.
- 5등급 × 보관·장착 프레임, 강조 복구, 비우기·아이콘 초기화 검증 통과.
- 실제 프리팹 렌더링: output/relic-slot-rarity/inventory-storage-equipped.png.
- 렌더링은 위에서부터 인벤토리·보관·장착이며 각 행은 빈칸·일반·고급·희귀·영웅·전설 순서다.
- 플레이 모드의 실제 유물 보관·장착 프레임 검증은 RelicPresentationVerification에 포함한다.
- 실제 유물 등급별 프레임, 드래그·장착·해제·페이지 이동 후 표시, 빈 칸 기본 배경 복원을 통과했다.
- 실제 프레임 4종의 5개 화면 배율 렌더링 검증도 통과했다. output/relic-presentation/verification.txt에 기록했다.
